研究費・公募情報収集システム
PDF自動取得システム 使い方ガイド
指定したWebページから、PDFを自動で集めて整理します
このシステムでできること
1
巡回する
登録したWebページを自動で開きます
2
見つける
ページ内のPDFリンクをすべて探します
3
保存する
サイト別・日付別のフォルダに整理して保存します
例：試験問題を掲載した1ページから、90件のPDFを約2分で取得できました
処理の流れ
STEP 1
設定を読む
sites.yaml
STEP 2
ページ取得
HTMLを読み込み
STEP 3
リンク抽出
.pdf を検出
STEP 4
重複確認
取得済みは除外
STEP 5
保存・記録
ログも出力
通信エラーは自動で再試行し、失敗した1件があっても、残りの処理は続けます
準備（初回のみ）
① Python 3.12 以上を用意する
お使いのPCに入っているか、コマンドで確認します
python --version
② 必要なライブラリを入れる
pip install -r requirements.txt
どちらも最初の1回だけで、次回からは不要です
実行のしかた
python src/main.py
やりたいこと
コマンド
すべてのサイトを巡回
python src/main.py
特定のサイトだけ実行
--site SiteA
設定ファイルを変更
--config 別ファイル.yaml
保存先を変更
--data-dir 保存先
巡回先は、config/sites.example.yaml を sites.yaml にコピーして、name と url を書きます
取得したPDFの保存先
data/
├ index.json
├ SiteA/
│ └ 2026-10-22/
│ ├ sample.pdf
│ └ sample_1.pdf
└ SiteB/
logs/2026-10-22.log
サイト名 → 取得日の順
フォルダは自動で作られます
同じ名前は連番
sample_1.pdf のように上書きされません
記録は2種類
index.json は取得済みの台帳、logs は実行の履歴です
毎日実行しても、新しいPDFだけ保存
チェック 1
URLで判定
取得済みのURLは、ダウンロードせずに飛ばします
チェック 2
中身で判定
SHA256という識別値が同じなら、別のURLでも保存しません
同じ名前で内容が違うPDFは、別のファイルとして連番で保存します
定期的に自動で動かす
プログラム自体に定期実行の機能はありません。Windowsのタスクスケジューラに登録します
schtasks /create /tn "PDF自動取得" /sc daily /st 08:00 /tr "python C:\...\src\main.py"
毎朝8時に実行
上のコマンドで登録できます
失敗はすぐ分かる
失敗があると終了コードが 1 になります
使うときの注意点
  • 巡回するのは、設定に書いたページ1枚だけです。リンク先のページへはたどりません
  • 既定ではrobots.txtを確認し、禁止されたページ・PDFは取得しません。取得するPDFの著作権は、元のサイトにあります
  • 相手サーバーに負担をかけないよう、1件ごとに1秒待ちます
  • 各サイトの利用規約を必ず確認してからお使いください
